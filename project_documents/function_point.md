# 功能点清单

## 一、用户与权限

- **用户登录**：基于用户名密码的登录验证，密码使用 bcrypt 哈希存储。
- **角色权限控制**：三种角色（admin/user/visitor），visitor 登录后仅提示无权限。
- **会话管理**：登录状态存储在 st.session_state，支持退出登录清除会话。

## 二、对话功能

- **多轮对话**：基于 thread_id 维护多轮对话记忆，上下文连贯。
- **对话记录持久化**：对话和消息分别存入 conversations 和 messages 表，刷新不丢失。
- **对话列表管理**：侧边栏展示所有对话，支持新建、切换、删除操作。
- **自动标题生成**：新对话的首条消息自动截取前 20 字作为对话标题。
- **相对时间显示**：对话列表显示"刚刚/分钟前/小时前/昨天"等相对时间。

## 三、智能体架构

- **Supervisor 路由**：接收用户问题，判断类型后转发给对应的 Sub-Agent，不直接作答。
- **RAG 文档问答 Agent**：调用 Dify 知识库 API，支持混合搜索、重排序，返回文档原文片段。
- **数据分析 Agent**：将自然语言转为 Python 代码，在沙箱中执行统计分析，支持多文件合并。
- **工具调用日志**：记录 Agent 调用的工具名称、参数和返回结果，可展开查看推理过程。

## 四、RAG 文档功能

- **知识库检索**：根据问题从 Dify 知识库检索相关文档片段，返回来源文件名。
- **文档列表查询**：查看知识库中有哪些文档，显示索引状态（已完成/处理中）。
- **内容仿写**：基于检索到的文档内容，按要求仿写新内容。

## 五、数据分析功能

- **文件列表查询**：列出数据目录中所有可用的 Excel/CSV 文件及完整路径。
- **文件结构检查**：读取 Excel 文件的列名和数据类型，为代码生成提供依据。
- **自然语言统计**：用中文描述统计需求，自动生成 Python 代码并执行，返回统计结果。
- **多文件分析**：支持同时分析多个月份的 Excel 文件，自动合并后统一统计。

## 六、代码沙箱

- **安全代码执行**：FastAPI 服务接收生成的 Python 代码，在子进程中执行，隔离主程序。
- **超时保护**：代码执行超时时间设为 30 秒，防止死循环阻塞系统。
- **临时文件清理**：执行完毕后自动删除临时脚本文件，不残留垃圾文件。

## 七、管理员功能

- **用户管理**：管理员可新建用户、修改角色（visitor/user/admin）、启用/禁用账号。
- **审计日志查询**：按用户名、操作类型、日期范围筛选日志，展示登录、对话、管理操作记录。
- **统计摘要**：仪表盘展示用户总数、今日活跃用户数、今日对话数。

## 八、审计与日志

- **操作记录**：所有登录、登出、对话、管理操作均写入 audit_logs 表，包含用户名、操作类型、使用的 Agent、问题内容、状态。
- **对话失败记录**：Agent 执行出错时，审计日志标记状态为 error，便于排查问题。

## 九、系统部署

- **一键启动脚本**：start.bat 自动创建虚拟环境、安装依赖、初始化数据库、启动所有服务。
- **数据库自动建表**：首次启动时自动创建 users、audit_logs、conversations、messages 四张表。
- **环境配置**：通过 .env 文件配置 API Key、知识库 ID、数据目录等参数。
