                           🚀 系统启动流程
═══════════════════════════════════════════════════════════════════════════════════

  start.bat / start.sh
     │
     ├── 1. 创建 Python 虚拟环境 (venv)
     ├── 2. pip install -r requirements.txt
     ├── 3. core/database.py 首次运行自动建表
     │         users / audit_logs / conversations / messages / document_history
     ├── 4. 启动代码沙箱服务 (code_executor.py)
     │         · multiprocessing.Pool(processes=N) 进程池预热
     │         · 每个 Worker 预加载 pandas
     │         · FastAPI uvicorn 启动, 默认端口 8100
     └── 5. 启动 Web 服务 (streamlit run app.py)
              · 加载 .env 配置
              · 初始化 LangSmith Tracing
              · 规则引擎懒加载 (首次调用时创建全局单例)
              · 监听 localhost:8501
