## 测试检查清单

在「接口查询」功能页面中，逐项验证以下能力：

- [ ] **参数 JSON 编辑** — Body 区域能否正确输入和格式化 JSON
- [ ] **必填参数校验** — 必填参数未填时，点击发送应拦截并提示具体缺失字段
- [ ] **目标地址可编辑** — Base URL 输入框能否手动修改
- [ ] **自动填充 Base URL** — 从 spec 的 servers 字段自动读取是否正确
- [ ] **GET 请求** — 测试无参数 / 有可选参数 / 有必填参数三种场景
- [ ] **POST 请求** — 测试带 JSON Body 的写入操作
- [ ] **响应展示** — 返回 JSON 是否格式化、状态码和耗时是否正确显示
- [ ] **异常处理** — 目标地址为空时 / 连接超时时 / 返回非 JSON 时的提示

---

## 注意事项

1. 以上所有接口均**无需认证 Token**，可直接测试
2. Base URL 统一为 `http://192.168.1.160:18888`（内网地址）
3. 部分接口虽然无必填参数，但实际后端可能会因缺少业务条件返回空结果，这属于正常行为
4. 测试时请注意**不要对生产环境做增删改操作**（POST/PUT/DELETE），优先使用 GET 接口验证
