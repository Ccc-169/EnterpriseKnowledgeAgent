企业知识库智能体系统是一个面向企业的智能知识管理平台，以阿里巴巴千问大语言模型为中枢，整合文档检索、数据分析和文档编写三大核心能力，提供 Web 界面与命令行双入口。系统基于 `LangGraph Supervisor `模式构建，用户问题经 Supervisor Router 智能分类后路由至对应子 Agent 处理：RAG 文档问答 Agent 通过查询改写、Dify 知识库语义检索、答案验证与自动重试，确保答案准确可溯源；数据分析 Agent 以文件列表、结构探查、代码生成、沙箱执行的三工具流水线，支持多文件合并统计与批量执行优化；文档编写 Agent 结合知识库检索与参考附件上传，经目录生成、用户确认、逐章分段生成，产出结构化 Markdown 文档。全流程接入规则引擎进行三阶段安全检查——输入端防提示词注入、代码端拦截危险调用、答案端做质量校验，仅 CRITICAL 级别违规阻断流程，兼顾安全与用户体验。系统具备完整的多轮对话体系，对话记忆持久化存储、智能标题生成、工具调用步骤可回溯；代码沙箱采用进程池预热和 namespace 隔离机制，消除冷启动开销并保障执行安全；同时内置三级角色权限管理、操作审计日志记录和管理员仪表盘统计。技术栈涵盖 Python、LangChain 与 LangGraph、Streamlit、SQLite（WAL 模式）、FastAPI、Dify API 以及 LangSmith 全链路追踪，通过 start.bat 脚本可实现一键部署，自动完成虚拟环境创建、依赖安装、数据库初始化和所有服务的启动。

以阿里巴巴qw3.6-plus模型为中枢，整合文档检索、数据分析和文档编写三大核心能力，提供 Web 界面与命令行双入口。系统基于 LangGraph Supervisor 模式构建，用户问题经 Supervisor Router 智能分类后路由至对应子 Agent 处理：RAG 文档问答 Agent、数据分析 Agent、文档编写 Agent 。
