企业知识库智能体系统是一个面向企业的 AI 智能知识管理平台，以阿里千问大模型为中枢，集成文档问答、数据分析、文档编写、API 接口调用四大核心能力，通过 Streamlit Web 前端与 FastAPI 后端（SSE 流式输出）双通道提供服务。系统采用 LangGraph Supervisor 多智能体协作模式，用户问题经 Router 智能分类后路由至对应子 Agent——RAG 文档问答 Agent 经查询改写、Dify 知识库语义检索与答案验证确保准确可溯源；数据分析 Agent 以文件探查、代码生成、沙箱执行的三工具流水线支持多文件统计与批量执行，内置 7 类数据模板可跳过文件探查直接生成分析代码，执行失败时仅修复出错行最多重试 2 次；文档编写 Agent 经目录生成、用户确认、逐章分段产出结构化 Markdown 文档；API 接口调用 Agent 实现接口发现、分组浏览、参数填充与一键调用。系统具备 Q&A 经验记忆能力，基于 Qwen Embedding v3 向量化历史问答对，相似问题（余弦相似度 ≥ 0.80）直接复用缓存答案避免重复检索。全流程受三阶段规则引擎管控——输入层防提示词注入、代码层拦截危险调用、答案层做质量校验，仅 CRITICAL 级别阻断流程；代码沙箱采用进程池预热与 namespace 隔离保障安全。同时内置三级角色权限管理、操作审计日志与管理员仪表盘，满足企业合规要求。技术栈为 Python / LangChain & LangGraph / Streamlit / FastAPI / SQLite WAL 模式 / Dify Rerank API / DashScope Embedding / LangSmith 全链路追踪 / JWT 认证，通过 start.bat 一键部署，自动启动四端口服务（Streamlit :8501 · FastAPI :8000 · Alarm Mock :8002 · 内部调度 :8100）。
