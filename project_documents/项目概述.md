HNGD-Backend 是一个面向企业场景的智能知识助手系统，采用“路由器 + 多智能体”架构，将文档检索和数据分析两类能力有机结合。系统核心由 agent.py 负责，它基于 LangGraph Supervisor 模式创建一个智能路由器，自动判断用户问题属于文档类还是数据类，并分别分发给 `rag_agent` 与 `data_agent`。`rag_agent` 负责企业知识库检索，调用 Dify API 检索文档内容、列出知识库文件、回答制度政策类问题；`data_agent` 则负责 Excel/CSV 数据统计分析，先列出文件、再检查列结构，最后生成 Python 代码并通过外部沙箱执行，完成考勤、排名、趋势对比等分析任务。

前端采用 Streamlit 实现，可视化对话界面支持用户登录、角色权限控制和多轮会话记忆。项目内置 `visitor`、`user`、`admin` 三类角色，管理页面仅对管理员开放，普通用户可以进行问答和数据分析。为了安全执行 LLM 生成的动态代码，系统通过 `code_executor.py` 提供一个 FastAPI 接口，把代码写入临时脚本并在子进程中运行，设置 30 秒超时和输出捕获，降低风险。

从整体来看，HNGD-Backend 的设计思想是“职责清晰、可扩展、可审计”：UI 层负责输入输出与权限，调度层负责路由与结果提取，智能体层负责领域任务，工具层负责实际执行。它既能处理企业文档检索问题，也能完成基于数据文件的统计分析，适合小规模本地部署和内部测试。技术栈包括 Python、Streamlit、LangGraph、langchain、FastAPI、pandas、openpyxl、SQLite 以及 Dify 知识库。该系统适合用作企业知识库智能问答和数据分析原型，加速内部信息查询与报表分析。
