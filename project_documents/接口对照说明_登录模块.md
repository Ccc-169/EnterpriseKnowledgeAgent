# 接口对照说明 — 登录模块

> 记录从 Streamlit 迁移到 HTML + FastAPI 时，每个旧操作对应的新接口/机制。

---

## 一、Streamlit 旧"接口"与 HTML 新接口对照表

| # | Streamlit 旧操作 | 所在文件 | 新 HTML 对应 |
|---|---|---|---|
| 1 | `authenticate_user(username, password)` | `auth/auth_service.py` | `POST /api/auth/login` 内部调用，前端无需直接调用 |
| 2 | 角色校验：`user["role"] != selected_role and user["role"] != "admin"` | `app.py:33-35` | API 同样校验并返回 `{"detail": "角色不匹配"}` → HTML 显示错误文案 |
| 3 | `login_session(user)` → 写 `st.session_state["current_user"]` | `auth/session.py` | API 返回 JWT token → 前端存入 `localStorage.setItem("token", ...)` |
| 4 | `log_event(user_id, username, "login")` | `audit/audit_service.py` | API 登录成功后内部自动调用，前端无感知 |
| 5 | `st.error("用户名或密码错误")` | `app.py:32` | 显示 `#error-msg`，文案：`账号或密码错误，请重新输入` |
| 6 | `st.error("该账号不是管理员账号...")` | `app.py:35` | 显示 `#error-msg`，文案：`该账号不是管理员账号，请切换登录身份` |
| 7 | `st.rerun()` → 跳转首页路由 | `app.py:39` | `window.location.href = 'home-page.html'` |
| 8 | `st.session_state["current_user"]` 在其他页面读取用户信息 | `auth/session.py` | 其他页面从 `localStorage.getItem("token")` 读取 JWT，解码获取用户信息；或每次请求在 Header 带 `Authorization: Bearer <token>` |
| 9 | `st.radio("选择登录身份", ["管理员", "普通用户"])` | `app.py:21` | `login-page.html` 中已有 `.role-selector` 组件，`selectedRole` 变量记录当前选择 |
| 10 | `st.form_submit_button("登录")` / Enter 键提交 | `app.py:27` | `#login-btn` 点击 + `keydown Enter` 事件（已有），调用 `handleLogin()` |

## 二、新接口规范

### `POST /api/auth/login`

**请求体（JSON）**

```json
{
  "username": "张三",
  "password": "123456",
  "role": "user"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `username` | string | 用户名 |
| `password` | string | 明文密码（HTTPS 传输） |
| `role` | string | 前端选择的身份：`"user"` 或 `"admin"` |

---

**成功响应 `200 OK`**

```json
{
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "user_id": 1,
  "username": "张三",
  "role": "user",
  "display_name": "张三"
}
```

| 字段 | 说明 |
|------|------|
| `token` | JWT，有效期 8 小时，存入 `localStorage` |
| `user_id` | 用户 ID，用于后续接口鉴权 |
| `username` | 登录用户名 |
| `role` | 实际角色：`admin` / `user` / `visitor` |
| `display_name` | 显示名称 |

---

**失败响应 `401 Unauthorized`**

```json
{ "detail": "用户名或密码错误" }
```

```json
{ "detail": "该账号不是管理员账号，请切换登录身份" }
```

```json
{ "detail": "该账号不是普通用户账号，请切换登录身份" }
```

## 三、Token 使用规范（供后续页面参考）

```javascript
// 登录成功后存储
localStorage.setItem("token", data.token);
localStorage.setItem("user", JSON.stringify({
  user_id: data.user_id,
  username: data.username,
  role: data.role,
  display_name: data.display_name
}));

// 其他页面读取
const token = localStorage.getItem("token");
const user  = JSON.parse(localStorage.getItem("user") || "{}");

// 带 token 调用受保护接口
fetch("/api/xxx", {
  headers: { "Authorization": "Bearer " + token }
});

// 登出时清除
localStorage.removeItem("token");
localStorage.removeItem("user");
```

## 四、visitor 角色处理

Streamlit 在 `app.py:47-56` 对 visitor 单独渲染无权限提示页。

HTML 方案：登录接口返回 `role: "visitor"` 后，前端跳转到 `home-page.html`，由该页面检测 role 并显示无权限提示，与 admin/user 走相同跳转路径，减少分支。

---

## 五、`auth/session.py` 的处置

该文件全部依赖 `st.session_state`，迁移后**不再使用**，`api.py` 直接调用 `auth/auth_service.py` 中的 `authenticate_user()`，session 概念由 JWT 替代。
