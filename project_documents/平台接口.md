### 1、报警趋势统计接口
- **请求方式**：`GET`
- **接口地址**：`/event-center/security-protection/alert-trend-statistics`

#### 请求参数（Query）
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| startTime | string | 是 | 开始时间（yyyy-MM-dd HH:mm:ss） |
| endTime | string | 是 | 结束时间（yyyy-MM-dd HH:mm:ss） |
| regionIndexCodes | array<string> | 否 | 区域索引码 |
| isSubRegion | boolean | 否 | 是否查询子区域数据 |
| eventTypes | array<string> | 否 | 事件类型列表 |

#### 示例 CURL
```bash
curl -X GET "http://192.168.1.160:18888/event-center/security-protection/alert-trend-statistics?startTime=2026-06-01%2000:00:00&endTime=2026-06-02%2000:00:00" -H "accept: application/json"
```

### 3. 获取安全生产报警统计
- **请求方式**：`GET`
- **接口地址**：`/event-center/alert/statistics/safety/production`

#### 请求参数（Query）
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| mapId | string | 否 | 厂区标识 |
| type | integer(int32) | 是 | 时间类型：1=本月，2=本季，3=本年 |

#### 示例 CURL
```bash
curl -X GET "http://192.168.1.160:18888/event-center/alert/statistics/safety/production?type=1" -H "accept: application/json"
```

### 5. 获取消防安全消防设备报警处置情况占比
- **请求方式**：`GET`
- **接口地址**：`/event-center/alert/statistics/fire`

#### 请求参数（Query）
| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| mapId | string | 否 | 厂区标识 |
| type | integer(int32) | 是 | 时间类型：1=日，2=月，3=年 |
| time | string($yyyy-MM-dd) | 是 | 指定时间，格式：yyyy-MM-dd |

#### 示例 CURL
```bash
curl -X GET "http://192.168.1.160:18888/event-center/alert/statistics/fire?type=1&time=2026-05-24" -H "accept: application/json"
```
