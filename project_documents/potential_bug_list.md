# 代码沙箱模块（code_executor.py）潜在Bug清单

## 🔴 严重程度：高

1. **进程池无并发控制**：当前实现缺少并发限制机制，100人同时提交代码执行请求时，`multiprocessing.Pool` 可能因任务积压导致响应超时或服务不可用。
2. **exec() 命名空间逃逸风险**：代码执行环境中暴露了 `os`、`sys` 等危险模块，恶意构造的代码可通过 `os.system()` 执行任意系统命令，绕过沙箱隔离。
3. **工作进程无内存回收机制**：未设置 `maxtasksperchild` 参数，长时间运行后 worker 进程内存持续增长无法释放，最终可能导致 OOM 崩溃。
4. **代码缓存跨进程失效**：`_code_cache` 字典在主进程中维护，但实际代码执行在子进程中进行，缓存机制完全失效，无法达到预期优化效果。
5. **超时处理不彻底**：`timeout=30` 仅中断 `.get()` 等待，后台进程仍在继续执行并占用资源，无法真正强制终止恶意死循环代码。
