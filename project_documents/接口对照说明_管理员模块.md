> 源文件：`pages/admin_page.py`

> **认证方式、公共约定**：见 [接口对照说明_对话模块.md](./接口对照说明_对话模块.md)，本文不重复。

## 一、权限守卫

| Streamlit 旧操作 | HTML 新对应 |
|---|---|
| `require_role(["admin"])` | `initPage()` 读 JWT，`user.role !== 'admin'` 时立即 `window.location.href = 'home-page.html'`（已实现于 admin-page.html） |
| `get_current_user()` | 从 `localStorage.getItem('user')` 解析；需要 `user_id` / `username` 的操作在请求时由服务端从 JWT 重新解析 |

## 六、新增 API 接口规范

> 所有接口均需 `Authorization: Bearer <token>`，且服务端校验 `role === 'admin'`，否则返回 `403`。

### `GET /api/admin/stats`

**响应** `200 OK`：

```json
{
  "total_users": 42,
  "active_users_today": 8,
  "total_chats_today": 156,
  "total_chats_all": 3042
}
```

---

### `GET /api/admin/users`

**响应** `200 OK`：

```json
[
  {
    "id": 1,
    "username": "admin",
    "display_name": "管理员",
    "role": "admin",
    "is_active": true,
    "created_at": "2024-01-15 10:30:00"
  }
]
```

---

### `POST /api/admin/users`

**请求**：`application/json`

```json
{ "username": "zhangsan", "password": "123456", "display_name": "张三", "role": "user" }
```

| 字段 | 必填 | 校验 |
|---|---|---|
| `username` | 是 | 非空，唯一 |
| `password` | 是 | 非空 |
| `display_name` | 否 | 最长 50 字 |
| `role` | 是 | `visitor` / `user` / `admin` 之一 |

**响应**：`200 OK` `{"ok": true}` / `409` `{"detail": "用户名已存在"}`

---

### `PUT /api/admin/users/{id}/role`

**请求**：`application/json`

```json
{ "role": "admin" }
```

`role` 枚举值：`visitor` / `user` / `admin`

**响应**：`200 OK` `{"ok": true}`

---

### `PUT /api/admin/users/{id}/active`

**请求**：`application/json`

```json
{ "is_active": false }
```

**响应**：`200 OK` `{"ok": true}`

> **限制**：服务端应禁止对当前登录用户自身执行此操作（`user_id == id` 时返回 `400`）。

---

### `GET /api/admin/logs`

**Query 参数**：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `username` | string | 否 | 精确匹配用户名 |
| `action` | string | 否 | `login` / `logout` / `chat` / `admin_op` / `denied` |
| `date_from` | string | 否 | `YYYY-MM-DD`，开始日期 |
| `date_to` | string | 否 | `YYYY-MM-DD`，结束日期 |
| `limit` | int | 否 | 默认 200，最大 500 |
| `offset` | int | 否 | 默认 0 |

**响应** `200 OK`：

```json
{
  "total": 42,
  "logs": [
    {
      "id": 1,
      "created_at": "2024-05-20 15:30:45",
      "username": "admin",
      "action": "login",
      "agent_used": null,
      "question": null,
      "status": "success"
    }
  ]
}
```

---

### `GET /api/admin/kb/datasets`

**Query 参数**：`page`（默认 1）、`limit`（默认 20）

**响应** `200 OK`（透传 Dify 响应结构）：

```json
{
  "data": [
    {
      "id": "uuid",
      "name": "产品手册",
      "description": "...",
      "document_count": 32,
      "word_count": 128000,
      "embedding_model": "text-embedding-ada-002"
    }
  ],
  "has_more": true,
  "total": 8
}
```

**特殊响应**：`503` `{"detail": "未配置 DIFY_DATASET_KEY，请联系管理员"}` — 前端显示 `#kb-unconfigured-tip`。

---

### `GET /api/admin/kb/datasets/{dataset_id}/documents`

```json
      "display_status": "已完成",
      "word_count": 4200,

    }
  ],
  "has_more": false,
  "total": 12
}
```

## 七、前端校验逻辑（无需请求 API）

| 校验场景 | 条件 | 提示文案 |
|---|---|---|
| 创建用户：必填项为空 | `username === ""` 或 `password === ""` | `用户名和密码为必填项` |
| 修改角色：未变更 | `new_role === current_role` | 不发送请求，无提示 |
| 禁用/启用：当前用户自身 | `row.id === localStorage.user.user_id` | 隐藏操作按钮（不显示操作列） |
