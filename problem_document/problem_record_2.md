**5 个核心瓶颈**：

### 1. 多文件查询始终失败，Agent 反复试错（最大瓶颈）

`execute_data_query` 的多文件逻辑有严重缺陷。第 1 次调用传入 12 个文件，返回：
```json
{"month": "1月", "total_days": 2920.0}, {"month": "2月", "total_days": 0.0}, ... {"month": "12月", "total_days": 0.0}
```
LLM 生成的 Python 代码将 12 个文件 concat 后按月汇总，但代码没有正确识别各文件的月份标签，只有第 1 个文件（1月）数据被统计，其余全是 0。Agent 反复尝试不同策略：全量→单文件→半年→全量→单文件……**共 5 次多文件查询全部失败**。

### 2. LLM 生成代码有 bug，缺乏自修复能力

第 12 次工具调用返回错误：
```
ValueError: could not convert string to float: '1970-01-011970-01-01...（12个拼接）'
```
根因在 `data_agent.py` 第 105 行的代码模板规则：
```python
# 规则7: 日期/时间列必须转字符串：df['日期列'] = pd.to_datetime(df['日期列']).dt.strftime('%Y-%m-%d')
```
考勤文件的「出勤天数」是整数列，被误识别为日期列，`pd.to_datetime(17)` 变成 `1970-01-01`，拼接后超长字符串导致 `float()` 崩溃。

### 3. 每次查询都需 LLM 生成代码 + 远程执行 = 双重耗时

每次 `execute_data_query` 内部流程：
```
用户 query → LLM 生成 Python 代码 (20-30s) → HTTP 请求 code_executor (5-15s) → 返回结果
```
query 每次不同，`_code_cache` 完全无效。26 次 LLM 调用 × 平均 15-30s/次 = 大量 API 等待。

### 4. 上下文不断膨胀，后期 LLM 调用越来越慢

| 阶段 | prompt_tokens |
|------|--------------|
| 首次调用 | 1,098 |
| 最终调用 | **17,894** |

每次 data_agent 决策 LLM 调用都携带全部历史工具调用和结果，包括大量 inspect_file 返回的巨型文本。17K tokens 的 prompt 在 qwen-plus 上约需 5-8s 纯 API 延迟。

### 5. 串行执行，无法并行

10 次 `execute_data_query` 完全串行执行。12 个月份的考勤统计无数据依赖，可并行查询，理论上总耗时可从 ~240s 降到 ~40s。

**耗时归因**：
```
LLM API 调用等待（生成代码 + 决策）  ≈ 140s  (38%)
代码执行（沙箱运行 Python）          ≈ 60s  (16%)
Agent 试错迭代（无效重试）            ≈ 120s (32%)
上下文膨胀导致的额外延迟              ≈ 30s  (8%)
其他（路由、文件检查等）               ≈ 20s  (6%)
```

**优化建议（按优先级）**：

| 优先级 | 优化项 | 预期效果 |
|--------|--------|----------|
| **P0** | 修复多文件查询：在 `execute_data_query` 中预设月份标签逻辑，不用 LLM 猜 | 消除 5 次无效重试，节省 ~120s |
| **P0** | 删除代码模板规则 7（日期列自动转换），改为按需转换或由 LLM 根据列类型判断 | 消除 ValueError 崩溃，节省 ~20s |
| **P1** | 预编译代码模板：对常见统计模式（求和、排名、月度汇总）使用参数化模板，跳过 LLM 代码生成 | 每次查询节省 20-30s |
| **P1** | 并行执行：多文件查询时按文件拆分为并行子任务，使用 `asyncio.gather` | 12 个月从 ~240s 降到 ~20s |
| **P2** | 压缩上下文：inspect_file 返回结果做摘要（只保留关键列名和 skiprows），减少 prompt 膨胀 | 减少 ~50% prompt tokens |
| **P2** | 增强错误自修复：代码执行失败时将错误信息直接传给 LLM 重新生成代码（而非由 agent 外层决策重试） | 减少决策轮次 |
