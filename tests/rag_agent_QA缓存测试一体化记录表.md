# rag_agent QA 缓存测试问题与耗时对照表

> 合并"问题对照表"与"耗时记录表"为一张大表，一行看完所有信息。
>
> 填表说明：
> - **原问题耗时** = 首次问原始问题的总耗时
> - **High 耗时** = 期望 < 2s；若明显偏长说明未真正短路
> - **Med/Low 耗时** = 理论上与原问题耗时同档，主要观察 LangSmith 中 `cache_check.level` 字段确认决策
> - 时间格式建议 `xx.xxs`
