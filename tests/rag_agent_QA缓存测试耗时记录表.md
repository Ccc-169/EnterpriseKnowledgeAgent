# rag_agent QA 缓存测试耗时记录表

> 配合 `tests/rag_agent_QA缓存三档置信度测试问题.md` 使用，将每档问题的实际耗时和命中档位填入对应表格。
>
> 填表说明：
> - **原问题耗时** = 首次问原始问题的总耗时（含 RAG + LLM 调取）
> - **High 耗时** = 期望显著低于原问题耗时（典型 < 2s，若无明显下降说明未真正短路）
> - **Med/Low 耗时** = 理论上与原问题耗时同档，主要观察 LangSmith 中 `cache_check.level` 字段确认决策正确
> - 时间格式建议 `xx.xxs`（秒，保留 1 位小数）

---
